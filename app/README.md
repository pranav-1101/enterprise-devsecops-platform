# Application Module

## Purpose

This directory contains the sample application used to demonstrate the complete DevSecOps lifecycle.

The application will serve as the deployment target for the CI/CD pipeline and will be used to validate automation across build, security scanning, containerization, deployment, and monitoring stages.

## Planned Components

- Sample web application
- Source code
- Build configuration
- Unit tests
- Application configuration

## Workflow

Application Source Code
        ↓
Build
        ↓
Code Quality Analysis
        ↓
Security Scan
        ↓
Docker Image
        ↓
Kubernetes Deployment
